# E-Commerce Shopping Website (MERN Stack)

## Project Overview
The E-Commerce Shopping Website is a full-stack web application developed using the MERN Stack (MongoDB, Express.js, React.js, and Node.js). The application provides a secure and user-friendly online shopping platform where customers can browse products, add items to the shopping cart, place orders, and make online payments.

## Features
- User Registration and Login
- Product Catalog
- Product Search and Filter
- Shopping Cart
- Secure Checkout
- Online Payment Integration
- Order Management
- User Profile
- Responsive Design

## Technologies Used
### Frontend
- React.js
- HTML5

### Backend

## Installation

### Clone the Repository

```bash
git clone https://github.com/your-username/ecommerce-shopping-website.git
```

### Install Frontend

```bash
cd client
npm install
npm start
```

### Install Backend

```bash
cd server
npm install
npm start
```
